# YT-ANSE

**YT Agent-Native Software Engineering**

A project-centered methodology and execution system for AI-native software development.

## System

```text
Project Knowledge (/docs)
        ↓
Progressive Specification
        ↓
Agent Orchestration
        ↓
Implementation
        ↓
Deterministic Review Engine
        ↓
Adversarial Review + Governance
        ↓
Verification + Integration
        ↓
Convergence / Best State
        ↓
Project Knowledge
        ↺
```

## Components

- `AGENTS.md` — repository constitution.
- `skills/yt-knowledge/` — project knowledge governance.
- `skills/yt-aose/` — progressive specification and agent orchestration.
- `skills/yt-review/` — review governance and review protocol.
- `engine/` — deterministic review execution substrate.
- `docs/` — methodology, ontology/terminology, state and integration specifications.

## Core principles

**Knowledge before Action.**  **Specification before Parallelism.**  **Determinism before Intelligence.**  **Evidence before Judgment.**  **Convergence before Perfection.**
