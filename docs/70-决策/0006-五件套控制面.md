# ADR 0006 — 五件套是控制面，不另建文档树

- 状态：已接受
- 日期：2026-09-29
- 不改：[ADR 0002](0002-排除-stepcode.md) 至 [ADR 0005](0005-进程内嵌入与插件删除.md) 的产品决定

## 背景

运行时替换是 L3：跨仓库、不可逆的嵌入方式已经接受。该决定作出时（2026-09-29）改接还没开始。T0–T4 已于 2026-09-30 完成，见 [检查点](../00-项目/检查点.md)。知识库已经用生命周期目录。YT-AOSE 要求 PRD、SPEC、ADR、PLAN、CHECKPOINT 各管一件事。两套规则如果各写一份全文，就会出现两个入口。

## 决策

1. 五件套映射到现有目录，不新建第二棵文档树。
   - PRD：[运行时替换](../20-需求/运行时替换.md)
   - SPEC：[替换契约](../30-开发/替换契约.md)
   - ADR：本目录。索引见 [README](README.md)
   - PLAN：[计划](../80-路线图/计划.md)
   - CHECKPOINT：[检查点](../00-项目/检查点.md)
2. PRD 只写意图和结果。接缝、输入输出、不变量和验收全文只在 SPEC。
3. PLAN 只保留未完成任务图。已完成步骤记在 CHECKPOINT。
4. 当前恢复只读 CHECKPOINT。`docs/99-归档/检查点/` 是历史，不是恢复锚点。
5. 不变量全文只在 SPEC。[质量页](../40-质量/不变量.md) 只指向它。
6. 改接任务写入范围重叠，不并行分派。

## 被否定的方案

- **再建 `docs/五件套/` 并复制五份正文**：与知识库唯一入口冲突。
- **把 CHECKPOINT 只放进归档**：恢复时会读到过期笔记。
- **为了凑 L4 补上没有证据的性能预算、新观测方案或发布通道**：`trace` 已决定删除且不迁。没有测量，就不能写成契约。
- **改写准则快照里的编排技能**：快照是锁定镜像。本 ADR 只约束本仓库的控制面。

## 后果

以后新增长期决定仍写 ADR，不写进 CHECKPOINT 的叙述。测试报告可以另记，但不得复制一份不变量全文。
