# 界面优化计划

本页是 [界面审阅](界面审阅-2026-10-01.md) 的执行顺序。它**不是** [运行时替换计划](../80-路线图/计划.md) 的一部分，不占 T 编号，不改变运行时边界。三档已于 2026-10-01 执行，验收记录在文末。

## 守住的判断

优化的目标是让这套桌面壳在安静、密度和反馈上站得住，不是把它改成一个有滚动叙事的网站。下面四条是边界，执行时不得越过：

1. 不改会话、工具裁决、确认弹窗的行为。视觉重构不得碰 `step-session.ts` 和主进程。
2. 不引入外链字体、外链图片、外链脚本。`index.html` 的 CSP 保持 `font-src 'self' data:`。要换字体就把它放进仓库。
3. 不新增权限档，不改「默认模式 / 完全信任」的用词。见 [ADR 0004](../70-决策/0004-gui-两档.md)。
4. 已有的焦点环、对比度修正、`focus-visible` 覆盖不得在重构中退步。审阅里把这些记为做得好的部分。

## 顺序

三档，按依赖排，不按视觉吸引力排。先立尺度，再收层级，最后才谈动效。顺序反了就会在没有尺度的界面上叠加动画，看起来更忙，不会更好。

### 第一档：立尺度

只动 `styles.css` 的令牌和基础元素，不动页面结构。做完之后，字号、间距、圆角、颜色都从令牌来，页面里不再手写 11.5px 这种中间值。

| 项 | 做法 | 完成判据 |
|---|---|---|
| 字号尺度 | 收成四级：12 标注、13 正文、15 小标题、20 页面标题。删掉 11、11.5、12.5 | 样式表里不再出现这四级之外的 `font-size` px 值 |
| 间距尺度 | 收成 4、8、12、16、24 五档 | 卡片、列表、表单的间距只取这五档 |
| 圆角尺度 | 收成 6、10、14 三档 | 不再出现 5、7、9 这类逐控件挑选的圆角 |
| 中性色 | 面板灰离开 VS Code 的 `#1E1E1E` / `#252526`，定一套自己的暖灰或冷灰，两档主题同步 | 暗色 `--bg` 不再是 `#1E1E1E` |
| 角色色与动作色分开 | `--director` 不再与 `--accent` 同值；编排三色降饱和，只在激活态给满色 | 浅色主题下 `--director` 与 `--accent` 不是同一个 hex |
| 等宽字体 | 要么把字体文件放进 `renderer/vendor/fonts` 并用 `@font-face` 引用，要么删掉 `"JetBrains Mono"` 这个不会生效的名字 | 样式表里点名的字体，要么在仓库里，要么不点名 |
| 调试声明 | 删除第 611–616 行的「调试」注释和两条 `min-height: 0 !important`，改成正常约束 | 样式表里不再有「调试」字样，不再有 `!important` |

这一档不追求好看。它的价值是让后面两档的改动有地方落，而不是每改一处就新写一个数。

### 第二档：收层级

动页面结构，仍不动行为。

| 项 | 做法 | 完成判据 |
|---|---|---|
| 欢迎页 | 把「从一句话开始。不会替你编任务。」从弱色小字提升到与问候同级的副题；问候本身降为标注 | 这句文案的字号不低于 15px，颜色用 `--fg` 而不是 `--fg-dim` |
| 会话标题 | 主区标题用上第一档的 20px 页面标题，与正文拉开一跳 | 会话标题与消息正文的字号差至少 5px |
| 徽章 | 一张插件卡默认只留一个状态徽章；能力徽章保持现有的「超出 3 个折叠」 | 默认状态下一张卡不超过一个状态徽章加三个能力徽章 |
| 悬停操作 | 会话行的操作按钮改为默认低对比可见，悬停提到满对比，不再用 `opacity: 0` | 不悬停也能看见这行有操作；悬停时布局不跳动 |
| 浮动按钮 | 「新建会话」的说明在 `:focus-visible` 时也出现，不只 `:hover` | 键盘聚焦该按钮时能看到文字说明 |
| 右栏重量 | 进行中的回合用 15px 的状态行表达，不再只靠 11px 副标题和脉冲 | 回合进行中时，右栏顶部有一行可读的状态，而不是只有动画 |
| 设置页分组 | 状态条、表单、列表之间用 24px 分隔，组内用 8px | 设置页能看出组，而不是一张长表 |

### 第三档：动效与窄窗

前两档落地后再做。动效只解释状态。

| 项 | 做法 | 完成判据 |
|---|---|---|
| 减弱动效 | 加 `@media (prefers-reduced-motion: reduce)`，关掉脉冲、缩放和位移 | 系统打开减弱动效后，界面不再有循环动画 |
| 脉冲语义 | 脉冲只留给「正在跑」这一处；完全信任档改成静态的颜色区分，不再循环 | `.composer .auth.full .dot` 不再有 `animation` |
| 过渡属性 | `transition: all` 改成显式属性，只过渡颜色、背景、边框 | 样式表里不再有 `transition: all` |
| 状态切换 | 消息进入列表、回合从进行中到完成，各给一个 150ms 以内的位移或淡入 | 两处过渡都能指出对应的状态变化，不是装饰 |
| toast | 补退出过渡，与进入的 200ms 对称 | toast 消失不是瞬切 |
| 窄窗 | 去掉 `min-width: 700px` 的硬裁切；700px 以下改为单列：隐藏 rail 文字、会话侧栏改为可拉出的抽屉 | 窗口拖到 600px 宽时主区仍完整可读，不出现横向滚动 |
| 矮窗 | 欢迎页在高度不足时改为顶对齐，依次让出问候和说明，输入框最后保留 | 窗口高度 500px 时输入框仍完整可见 |

## 明确不做

- 不做首屏大图、视差、滚动驱动动画。这是桌面工作台，不是获奖站点的展示页。
- 不做新的主题市场，也不做第三套主题。两套主题先把尺度对齐。
- 不改 logo 的图形，除非第一档定下了自己的颜色。在颜色没定之前换图形没有意义。
- 不把「ZCode 风格」换成另一款产品的名字。要么做成自己的，要么不写这个注释。第二档结束时，这两处注释应当被删除，因为届时样式不再需要借另一个名字来解释。

## 验收

每一档单独验收，不三档一起看。验收只问本页「完成判据」列里的话，不另加感觉分。

- 第一档用样式表检索验收：不该出现的 px 值、字体名、`!important` 和「调试」字样，检索结果为空。
- 第二档用渲染结果验收：打开欢迎页、一条有消息的会话、插件页、设置页，逐条对判据。
- 第三档用系统设置验收：打开减弱动效后走一遍发送和收起侧栏；把窗口拖到 600px 宽、500px 高，主区仍可读。

未执行的档不得在 [当前状态](../00-项目/当前状态.md) 里写成已完成。

## 2026-10-01 执行记录

三档一次落地，验收按本页判据，不另加感觉分。

- 第一档：样式表检索确认字号只剩 12、13、15、20 四级，`transition: all`、`JetBrains Mono`、「ZCode」、「调试」均为空。暗色 `--bg` 改为 `#1C1917`，`--director` 与 `--accent` 不再同值。等宽字体改为系统自带的 Consolas，未引入外链。
- 第二档：欢迎页那句文案升到 15px 副题，问候降为 12px 标注。会话标题与页面标题同为 20px。插件卡默认只留一个状态徽章。会话行操作改为默认 0.45 对比，悬停提到满对比。浮动按钮的说明在 `focus-visible` 时也出现。右栏状态行升到 15px。
- 第三档：补了 `prefers-reduced-motion`，脉冲只留在「正在跑」的步骤点、打字头像和工具行。toast 退出与进入同为 200ms。去掉 `min-width: 700px`，700px 以下侧栏改为抽屉，导航轨顶部给出入口。窗口高度不足 560px 时欢迎页改为顶对齐。

未做的一项要记清：第三档的「系统设置里打开减弱动效后走一遍」没有在真机上做，验收依据是样式表里的媒体查询，不是一次手动走查。

`!important` 还剩三处，都不是调试残留：窄窗隐藏右栏、代码高亮透明底、减弱动效关掉动画。前两处没有它就会被更高优先级的规则盖住。
