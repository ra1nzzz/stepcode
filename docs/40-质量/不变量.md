# 不变量

权威全文在 [SPEC](../30-开发/替换契约.md)。本页不重复清单，避免两份不变量互相改口。

尚无测试套件。以后的测试报告可以记在本层，但不得另写一份不变量。

本仓库自己没有测试套件。OrchDesk 侧的验证脚本结果记在 [检查点](../00-项目/检查点.md)，不在本层另写。
