# 责任边界

一个事实类型只有一个 canonical 责任页。其它副本是镜像或归档。

| 事实类型 | 责任页 | 不是责任页的副本 |
|---|---|---|
| 当前产品状态 | [当前状态](当前状态.md) | 归档中的检查点、研究、旧参考 |
| 可恢复基线 | [可恢复基线](可恢复基线.md) | 无 |
| 术语 | [术语](术语.md) | 无 |
| 来源与锁定点 | [来源并入](来源并入.md) | `guidelines/` 是准则镜像，不拥有产品锁定点 |
| 冲突 | [冲突裁决](冲突裁决.md) | 不得在其它页静默改口 |
| 架构 | [运行时边界](../10-架构/运行时边界.md) | 无 |
| 需求 | [运行时替换](../20-需求/运行时替换.md) | 路线图不改写已接受需求 |
| 开发合同 | [替换契约](../30-开发/替换契约.md) | 无应用代码可充当合同 |
| 质量门禁 | [不变量](../40-质量/不变量.md) | 无测试套件 |
| 发布 | [发布状态](../50-发布/发布状态.md) | 仓库存在不等于已发布产品 |
| 缺陷 | [BUG 索引](../60-BUG/索引.md) | 未核对项不是缺陷 |
| 已接受决定 | [70-决策](../70-决策/0001-采用-yt-anse.md) | 研究笔记不是决定 |
| 未来工作 | [计划](../80-路线图/计划.md) | 已完成步骤不是当前工作 |
| 历史 | [归档索引](../99-归档/README.md) | 不得把归档写成现在时 |

本仓库拥有 stepcode 的项目知识。`stepfun-ai/Step-Code` 拥有上游 CLI。`ra1nzzz/orchdesk` 拥有待替换宿主，历史独立，本增量不并入。`stepcode/stepcode` 已排除。
